# little-harness-rich

A pluggable Terminal User Interface (TUI) for the `little-harness` LLM agent harness, built using [rich](https://github.com/textualize/rich).

## Installation

This is an extension package. You can install it as part of `little-harness` via:

```bash
pip install "little-harness[rich]"
```

## Usage

Specify `--ui rich` when running `little-harness` in interactive mode:

```bash
little-harness --ui rich
```
